MY fav plyliste — starter website

WHAT IT DOES
- Responsive dark/black/purple playlist page.
- Add a song title, artist, platform and Spotify/YouTube URL.
- Play button opens the official link in a new tab.
- Delete songs from the list.
- This starter stores the list in the current browser/device using localStorage.

IMPORTANT LIMITATION
The list is stored only in the browser on that device. It does NOT sync between devices or visitors. For a public shared playlist where edits appear for everyone, add a database and admin authentication (for example Supabase/Firebase) in a later version. Do not put passwords or private keys in this static HTML.

PREVIEW
Open index.html in a browser.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in at https://github.com/ and create a new public repository, e.g. my-fav-plyliste.
2. Upload index.html to the repository root.
3. Open the repository Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
5. Wait for deployment and open the URL shown in Settings -> Pages. It will look like https://YOUR-USERNAME.github.io/my-fav-plyliste/
6. Add that URL to Instagram -> Edit profile -> Links -> Add external link.

You can edit index.html later and upload the updated file to the repository.

This website links to Spotify/YouTube rather than hosting copyrighted audio files.
